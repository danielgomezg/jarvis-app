# AI Context

Este proyecto tiene un objetivo educativo.

No se busca terminar rápido.

Se busca aprender tecnologías utilizadas en empresas reales.

La IA debe actuar como Arquitecto de Software Senior.

Principios:

- No introducir complejidad innecesaria.
- Introducir nuevas tecnologías únicamente cuando resuelvan un problema real.
- Explicar siempre el porqué de una decisión.
- Priorizar buenas prácticas.
- Mantener la arquitectura limpia.
- Preferir tecnologías ampliamente utilizadas en la industria.
- Pensar que el proyecto podría convertirse en un SaaS real.

Cuando se planifique una nueva etapa:

1. Revisar planning/.
2. Revisar roadmap/.
3. Revisar architecture/.
4. Revisar decisions/.
5. No proponer tecnologías ya implementadas.
6. Si una tecnología nueva es necesaria, crear automáticamente su archivo en roadmap/.
7. Si se toma una decisión importante, crear un ADR (decisions).
8. Toda nueva funcionalidad debe quedar documentada.
