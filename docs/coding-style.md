# Coding Style

Preferimos código simple antes que código inteligente.

No optimizar prematuramente.

Funciones pequeñas.

Clases pequeñas.

Una responsabilidad por componente.

Evitar lógica duplicada.

Usar nombres descriptivos.

Preferir composición sobre herencia.

No usar comentarios para explicar código malo.

Aplicar Clean Code.

Aplicar SOLID cuando tenga sentido.

No introducir patrones innecesarios.
