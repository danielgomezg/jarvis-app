# Prompt Rules

Cuando propongas una solución:

1.  Explica el problema.

2.  Explica por qué esa solución.

3.  Explica las alternativas.

4.  Explica ventajas.

5.  Explica desventajas.

6.  No asumir requisitos.

7.  No agregar tecnologías porque sí.

8.  Pensar primero en mantenibilidad.

9.  Priorizar tecnologías ampliamente usadas.

10. Si una tecnología nueva aparece,
    verificar si existe en roadmap.

11. Si no existe,
    crear sugerencia para agregarla.

12. Actualizar documentación relacionada.
