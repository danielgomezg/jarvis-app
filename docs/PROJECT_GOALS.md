# Objetivos del proyecto

El proyecto Jarvis tiene como objetivo principal ser un entorno de aprendizaje profesional.

No se prioriza terminar rápido.

Se prioriza:

✔ Clean Architecture

✔ Clean Code

✔ Testing

✔ Docker

✔ CI/CD

✔ Cloud

✔ Microservicios

✔ Seguridad

✔ Observabilidad

✔ Escalabilidad

Cada tecnología debe implementarse cuando exista una necesidad real.

El proyecto debe evolucionar como lo haría un SaaS utilizado por clientes reales.
